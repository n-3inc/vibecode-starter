# vibecode starter

AIとの会話だけでアプリを開発する「バイブコーディング」専用スターターキットです。

### このキットを使うと
- **コードを一切書かずに** AIに何を作りたいか伝えるだけでブラウザで動くアプリが完成します
- AIに **こういう機能を追加して** と伝えるだけでアプリが修正できます
- 作ったアプリはPC上で実行し、ネットワーク経由で他の人も利用できるようになります

## こんな場面で活躍します
- 毎日同じ作業を繰り返しているが、プログラミングの知識がないため自動化できない
- アイデアはあるが、コードを書くのが面倒で実装できない
- コーディングの知識はあるが、細かい実装に時間を取られたくない

## 開発できるアプリの例
- 人事・総務: 社内アンケートの集計・ダッシュボード
- 経理・財務: 経費精算の自動化ツール
- 営業: 顧客管理ダッシュボード
- 工場・製造: 在庫チェックツール・生産スケジュール管理ツール
- カスタマーサポート: FAQ検索ツール・問い合わせ内容の自動振り分けツール

### 事前準備
- Claude Subscriptionの登録 ([登録ページ](https://claude.com/pricing))
- Node.jsとnpmのインストール ([インストール手順](https://nodejs.org/ja/))
- Cloudflareアカウントの作成 ([作成ページ](https://dash.cloudflare.com/sign-up))
- Visual Studio Codeのインストール ([インストールページ](https://marketplace.visualstudio.com/items?itemName=anthropic.claude-code))

## 開発の進め方
1. AIに作りたいアプリの内容を伝える
2. AIが指定された機能を実装する
3. Google Chrome で http://localhost:5173 を開いて、アプリの動作を確認する
4. 修正したい点を AI に伝えると、AIが自動的にコードを修正、ブラウザの表示が自動更新される

コードを書く必要はありません。AIに指示するだけでアプリが完成します。

## 開発したアプリをクラウドに公開する
- wrangler.jsonファイルを開き、"name"の値を任意のアプリ名に変更する
```bash
# 変更前 (半角英数字とハイフンのみ使用可能)
"name": "example-app",

# 変更後 (例)
"name": "my-first-app",
```
- VS Codeのターミナルを起動する
- 認証情報を取得する
```bash
# 以下のコマンドを実行するとブラウザが起動するので、Cloudflareアカウントでログインする
npx wrangler login
```
- アプリをクラウドにデプロイする
```bash
# VS Codeのターミナルを開き、以下のコマンドを実行する
# (注)以下のコマンドを実行すると、アプリがクラウドにデプロイされ、インターネット経由でアクセスできるようになります
pnpm run deploy
```
- https://dash.cloudflare.com/ にアクセス
- 作成したアカウントをクリック
- 左側のメニューから「設定」をクリック、設定画面が開いたらチーム名をコピーしておく※1
```bash
例: n-3
```
- 左側のメニューから「コンピュート > Workers & Pages」をクリック
- 作成したアプリをクリック
- 「設定」タブをクリック
- 「ドメインとルート」セクションの「タイプ: workers.dev」の右側メニューから「Cloudflare Access」を有効化
- 画面に表示された「オーディエンス (AUD)」をコピーしておく※2
```bash
例: 0f312a149dd0d93847b32aed91bcbde123b53ce973c96ae17a323939e510ec07
```
- プロジェクトルートのwrangler.jsonファイルを開き、"vars"セクションに以下の2つの環境変数を追加する
```
# 変更前
"vars": {
    "ACCESS_TEAM": "この値はCloudflare Accessのチームドメインに置き換えてください",
    "ACCESS_AUD": "この値はCloudflare AccessのアプリケーションIDに置き換えてください"
}

# 変更後
"vars": {
    "ACCESS_TEAM": "※1でコピーしたチームドメインの値をここに貼り付け",
    "ACCESS_AUD": "※2でコピーしたオーディエンスの値をここに貼り付け"
}
```
- 環境変数を更新するため、アプリケーションを再デプロイする
```bash
pnpm run deploy
```
- アプリのURLにアクセスすると、Cloudflare Accessのログイン画面が表示されるようになります。ログイン後、アプリにアクセスできることを確認してください。
