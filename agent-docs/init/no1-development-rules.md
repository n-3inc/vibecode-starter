# 開発ルール

## 開発ワークフロー
### 0. 初期化
- 新しいセッションを開始したら、最初にポート 5173 が空いていることを確認する。
  - macOS / Linux: `lsof -i :5173`
  - Windows: `netstat -ano | findstr :5173`
- もしプロセスが存在する場合は強制終了する。
  - macOS / Linux: `kill -9 <PID>`
  - Windows: `taskkill /F /PID <PID>`

### 1. 機能実装 → アプリ起動サイクル
- ユーザーから受けた機能依頼をを実装する
- 実装後、アプリが起動していなければ `pnpm dev` でアプリを起動
- まずは自分で動作確認をし、問題なければユーザーに動作確認してもらう
- サイクル: **ユーザーの指示 → 修正 → 自動リロード → ユーザーが確認**

### 2. サブエージェント戦略
- メインコンテキストを汚さないためサブエージェントを積極活用する
- リサーチ・探索・並列分析はサブエージェントに委ねる
- 1 サブエージェント = 1 タスク に徹する

### 3. 完了前の検証
- 動作確認なしにタスク完了とマークしない
- 「スタッフエンジニアが承認するか？」と自問する
- アプリが起動済みであることを確認する

### 4. エレガントさを要求（バランス重視）
- 非自明な変更では「より優雅な方法はないか？」と一時停止する
- ハック的な修正に気づいたら: 「今知っていることすべてを踏まえてエレガントな解を実装する」
- 明白な小さな修正には過剰設計しない

### 5. 自律的バグ修正
- バグレポートを受けたら即修正。ハンドホールドを求めない

## 環境変数の管理
- `.env.vars` はエージェントが管理する。ユーザーは手動編集しない
- 外部サービスのAPIキーや、データベースのパスワード管理等が必要になった場合は、必要に応じてユーザーに値を確認し`.env.vars`を修正すること。
- ただし、ユーザーの同意なしに`.env.vars`内の既存キーを勝手に削除・変更しないこと。

## コードスタイル規約

本プロジェクトのスタックは TypeScript + React + Hono。Python は使わない。

### TypeScript
- **strict モード前提**: `any` を使わず型推論と明示的な型で書く。`unknown` で受けて narrow する
- **未使用変数・引数は禁止**: `noUnusedLocals` / `noUnusedParameters` が有効。使わない引数は `_` プレフィックスで明示
- **外部入力は検証する**: リクエストボディ・クエリ・環境変数など信頼できない値は、使用前に型とバリデーションで守る
- **セミコロン**: 使用しない（既存コードに合わせる）
- **クォート**: ダブルクォート `"..."`
- **インデント**: スペース2つ

### React
- **関数コンポーネント + Hooks のみ**。クラスコンポーネントは作らない
- **React Hooks ルールを遵守**（`eslint-plugin-react-hooks`）: Hooks は条件分岐・ループ内で呼ばない
- **Fast Refresh 対応**: コンポーネントファイルからはコンポーネントのみ export する（定数やユーティリティの同居は避ける）
- **コンポーネントは default export**、ユーティリティ・フック・型は named export を基本とする

### 命名
- コンポーネント・型: `PascalCase`
- 関数・変数: `camelCase`
- 定数（環境値など）: `SCREAMING_SNAKE_CASE`
- ファイル: コンポーネントは `PascalCase.tsx`、それ以外は `camelCase.ts`

### インポート
- パスエイリアスは未設定。相対パスで書く
- 外部ライブラリ → 内部モジュール → スタイル/アセット の順に並べる

### 完了前に必ず通すコマンド
- `pnpm lint` — ESLint
- `pnpm check` — `tsc` 型チェック + `vite build` + `wrangler deploy --dry-run`

どちらかでもエラーが出たら完了としない。

## コアプリンシプル

- **手抜きなし**: 根本原因を探す。一時的な修正をしない。シニアエンジニアの基準で
- **最小インパクト**: 必要な箇所だけ変更する。バグを混入させない
